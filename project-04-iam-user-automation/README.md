# Project 4 \- IAM User Automation with Terraform

## Objective

Create an IAM user with controlled permissions using Terraform.

## Resources Created

- IAM User
- IAM Policy Attachment

## Configuration

User Name: project4\-s3\-reader

Policy: AmazonS3ReadOnlyAccess

Policy ARN was stored as a Terraform variable.

## Verification

The IAM user was created successfully and the S3 read\-only policy was attached.
