# Project 20 - Load Balanced App Deployment

## Objective

Improve application scalability and availability using an Application Load Balancer.

## Tasks Performed

- Deployed two EC2 instances
- Created Target Group
- Configured Health Checks
- Created Application Load Balancer
- Registered EC2 instances as targets
- Verified traffic delivery through ALB

## Components

- Web Server 1
- Web Server 2
- Target Group
- Application Load Balancer

## Verification

Both EC2 instances successfully passed health checks and traffic was served through the Application Load Balancer endpoint.
