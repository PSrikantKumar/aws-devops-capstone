# Project 14 - App Deployment using EKS

## Objective

Deploy a containerized application to Amazon Elastic Kubernetes Service (EKS) and expose it publicly.

## Cluster Details

Cluster Name:
psrikant-project14-eks

## Tasks Performed

- Created EKS Cluster
- Added Worker Nodes
- Connected using kubectl
- Created Kubernetes Deployment
- Created LoadBalancer Service
- Deployed Docker image from ECR
- Exposed application publicly

## Verification

The application was successfully accessed through the public LoadBalancer endpoint.
