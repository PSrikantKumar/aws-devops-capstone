# Project 23 - IAM Role Based Access

## Objective

Provide secure access to AWS resources using IAM Roles instead of access keys.

## Tasks Performed

- Identified an EC2 instance
- Selected an IAM instance profile
- Attached an IAM role to EC2
- Verified Amazon S3 access using AWS CLI

## Verification

Role-based authentication was used to access S3 resources without embedding AWS access keys.
