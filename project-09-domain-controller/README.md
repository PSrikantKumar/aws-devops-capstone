# Project 9 - Domain Controller Setup

## Objective

Practice Active Directory Domain Services (AD DS) administration by creating a domain controller and managing domain users.

## Tasks Performed

- Installed Active Directory Domain Services
- Promoted the server to a Domain Controller
- Created a new forest: capstone.local
- Created domain users:
  - abhijeet
  - bharat
- Added users to the Remote Desktop Users group

## Verification

The domain users were successfully created and authenticated by Active Directory.

## Project Note

The training environment restricted Remote Desktop logon rights for standard domain users on the Domain Controller. Authentication succeeded, but authorization to establish an RDP session was denied by policy.
