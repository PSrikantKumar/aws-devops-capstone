# Project 10 - Internal DNS Setup

## Objective

Configure internal DNS name resolution using Active Directory Integrated DNS.

## Tasks Performed

- Verified DNS Server role
- Opened DNS Manager
- Created A Record for web server
- Mapped hostname to web server IP
- Verified DNS resolution using nslookup

## DNS Configuration

Hostname:
web.capstone.local

Record Type:
A Record

## Verification

Successfully resolved the hostname using nslookup.
