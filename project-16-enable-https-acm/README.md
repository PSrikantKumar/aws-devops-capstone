# Project 16 - Enable HTTPS using ACM

## Objective

Secure web access using AWS Certificate Manager (ACM) and an Application Load Balancer (ALB).

## Intended Tasks

- Request ACM certificate
- Configure HTTPS listener on ALB
- Redirect or block HTTP traffic
- Verify HTTPS access

## Lab Environment Constraint

The AWS training account did not provide:

- A registered domain name
- Route 53 hosted zones
- Sufficient ACM permissions

Because ACM public certificates require domain validation, certificate issuance and HTTPS listener configuration could not be fully completed.

## Verification

The ACM workflow, prerequisites, and validation requirements were reviewed and tested within the available permissions.
