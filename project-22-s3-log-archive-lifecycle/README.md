# Project 22 - S3 Log Archive with Lifecycle

## Objective

Reduce storage costs by automatically expiring old log files.

## Tasks Performed

- Uploaded log files to Amazon S3
- Created lifecycle policy
- Configured expiration rule
- Verified lifecycle configuration

## Lifecycle Policy

Expiration:
30 Days

Status:
Enabled

## Verification

The lifecycle rule was successfully applied and visible within the S3 bucket management configuration.
