# Project 1 - Terraform EC2 Web Server 

## Objective

 Deploy an EC2 web server using Terraform.

 ## Resources Created
 - EC2 Instance
 - Security Group
 - Apache Web Server

 ## Special Note
 The AWS lab account had reached the VPC quota limit, therefore the implementation reused the default VPC instead of creating a new VPC.

 ## Verification
 The web application was accessible via the EC2 public IP.
